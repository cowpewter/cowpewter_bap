# Changelog v0.1.0-alpha to v0.2.0-alpha

## Removed

* BlockRunner
* Explorer's Compass
* Better Archeology
* Caelus
* Caged and Boxed
* Elytra Slot
* Panda's Falling Trees
* wd's Selling Bin
* Sophisticated Storage
* Waystones
* Xaero's Waystones Compat
* Icon Xaero's

## Added

* Yung's Better Mineshafts
* Monolib
* More Useful Copper
* Icon Fresh

## Changes

Placeholder quests completely removed, new questline written (Some text is still WIP). No AI-generated text remains in the pack.

Stripped mods that didn't fit the tone or theme of the pack, like Caged and Boxed and Better Archeology, or were being buggy but are purely cosmetic like Falling Trees, or that duped functionality already in other mods, like BlockRunner. Removed Waystones to make Via Romana actually worthwhile.

Added Yung's Better Mineshafts cause its prolly the only structure players will interact with.

Block stacks will top up from inventory when about to run out, and broken tools will be auto-replaced from inventory.

Added copper tools for smoother early game. Nerfed copper to 1 raw per ore.

Emeralds replaced with custom currency and coin pouch, auto-equipped to coin_pouch curio slot. Press P to open pouch.

Replaced wd's Selling Bin with custom shipping bin implementation. Coins auto-added to coin pouch with overflow to inventory to floor.

Ringing the copper bell (regular bell is not obtainable) summons Wandering Trader, with a cooldown of 1 MC day.

Removed Sophisticated Storage because frankly it adds more items than like all the other mods combined. Vanilla storage should be sufficient for pack.

Harvesting crops grants XP.
