# Changelog v0.2.1-alpha to v0.3.0-beta

## Removed

## Added

* Reliable Name Tags

## Changes

New coin sprites

New shipping bin texture (edited vanilla chest)

Added a Guide Book item that is given to the player on start, and can be right-clicked to open QuestLog, as otherwise the only explanation of the keybind for QuestLog is IN QuestLog

Price tooltips added to all shippable items. Hover in your inventory or JEI to see unit price.

Added Reliable Name Tags for renaming without an anvil (right-click nametag in air)

Added a stub mod jar `cowpewter_bap.jar` to allow JEI to display a nice looking name instead of the namespace for items I added with KubeJS. Contains no code, only a metadata file.
